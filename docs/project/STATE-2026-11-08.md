## What it is
A 2-to-5-player online board game for family play on phones: ostrich versus vulture (classic), hunters (hyena, badger), 2v2 and bot players. Built by AI coding agents (Cursor cloud agents driven from a Grok bot called "Ostrich Game" in the Movement Institute Grok workspace) between 2026-11-02 and 2026-11-06. Brian is the designer and playtester.
